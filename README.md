# 📊 Interactive Sales & Profitability Power BI Dashboard

An executive-level, interactive two-page Power BI dashboard designed to analyze high-level sales performance, product profitability, and regional distributions.

---

## 🛠️ Key Features & Interactivity
- **Dynamic Field Parameters:** Seamlessly toggle trend metrics between **Total Revenue**, **Total Profit**, and **Units Sold** without cluttering the canvas.
- **Executive Overview (Page 1):** Highlights top KPIs (Revenue, Profit, Margin %, YOY Growth) alongside category dominance and top-performing products.
- **Profitability & Regional Analysis (Page 2):** In-depth evaluation of regional revenue, sales channels, and product-level profitability margins.
- **Interactive Slicers:** Synchronized filtering by Year, Region, Category, and Sales Channel across pages.

---

## 📐 Data Modeling & DAX Measures
- **Data Model:** Structured STAR schema with custom Calendar tables and distinct dimension tables for optimized performance.
- **DAX Calculations:** Custom measures implemented for core business metrics including:
  - `Total Revenue`
  - `Total Profit`
  - `Profit Margin %`
  - `YOY Growth %`

---

## 📂 Repository Contents
- **`*.pbix` File:** Complete Power BI report with interactive visuals and DAX calculations.
- **Dataset File:** Raw data source utilized for cleaning, transformation, and modeling.
- **Dashboard Screenshots:** High-resolution previews of Page 1 and Page 2.
